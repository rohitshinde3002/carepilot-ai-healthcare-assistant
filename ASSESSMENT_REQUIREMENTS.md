# Task 1 requirements mapped from the supplied PDF

## Challenge
Create ONE project in Healthcare or Technology using AI tools. Directions include website development, digital marketing, web scraping/data intelligence, automation, or innovation/new ideas. CarePilot is a healthcare-focused functional web application / innovation prototype.

## Important requirements
- AI tools must play a meaningful role in development.
- Project must relate to healthcare or technology.
- Demonstrate skills, creativity, problem-solving, and effective AI use rather than only presenting an idea.
- Any AI tools, languages, frameworks, and supporting technologies may be used.

## All three submission items
1. **Video presentation — minimum 2 minutes:** AI tools and why; prompt design/refinement; approach and prior knowledge; challenges and solutions; final outcome/demo.
2. **Prompt documentation:** all prompts used plus significant revisions/follow-up prompts.
3. **Project link:** GitHub, live website/app, Google Drive folder, or working prototype. Ensure access; if not hosted, include files and run instructions.

## Evaluation
Practical AI use; prompt engineering and iteration; creativity/innovation; problem-solving and technical execution; usefulness/quality; ability to explain decisions and demonstrate the build.

## Submit
Email to **jobs@gokulinfocare.com**. PDF states there is no set deadline and selection is first-come, first-served. For large files, use Google Drive and enable access for anyone with the link.
